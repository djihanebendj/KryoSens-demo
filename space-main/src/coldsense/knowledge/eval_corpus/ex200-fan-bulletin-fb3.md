# Service Bulletin FB-3: EX-200 evaporator fan motor

> SYNTHETIC TEST DOCUMENT. Fictional bulletin with invented values, written for ColdSense tests.

## Applicability

EX-200 units with evaporator fan motor type M2.

## Replacement part

Replace a failed M2 fan motor with part number FM-118. The FM-118 draws 0.35 A.

## Caution

Do not run the evaporator fans with the fan guard removed.
